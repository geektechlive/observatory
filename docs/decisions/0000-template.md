## Context

The forces and facts that made a decision necessary. What was true, what was measured, what was
proposed. Facts only; link the evidence below rather than restating it at length.

## Decision

What was decided, in one or two short paragraphs. Name who decided by role ("the owner").

## Consequences

- What it enables.
- What it costs, and which alternatives it rules out.
- What would have to be true to revisit it. A decision without a revisit condition reads as
  permanent; say so if it is.

## Evidence

- Files, commits, issues and docs that back the decision. Anchor code references on a searchable
  string or a commit SHA, not a bare line number (line numbers rot).
- Every item must exist in the repo when the ADR is written.
